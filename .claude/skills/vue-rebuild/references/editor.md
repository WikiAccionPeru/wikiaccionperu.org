# Editor spec
- CodeMirror 6 (`@codemirror/lang-markdown`), toolbar buttons insert directive snippets; optional preview pane below using the same `<ContentRenderer>`.
- Toolbar: bold/italic/link/heading/list · `EditorCommonsFileInserter.vue` (debounced search `action=query&generator=search&gsrnamespace=6&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=300` on commons.wikimedia.org, pick → `![alt](url "caption")` or `::commons-file{name="File:…"}` to keep license/attribution) · `::commons-category{name="Category:…" mode="carousel|gallery" width="…"}` · `::article-card{title="…" words="40"}` (MediaWiki REST `page/summary`, cached) · `::photo-bg{src alt overlay}` (alt required).
- Properties form above the editor, **closed choices where options are limited**: type and status (dropdowns; status = publish | draft), date (picker), categories/tags/focus area (`EditorTermPicker`: checkboxes for few options, type-ahead restricted to existing terms for many). Free text only for title and summary. Structured pages (home) are edited section by section with `EditorPageFieldTree`.
- Save = `PUT /api/admin/page` (editor only, same-origin) → frontmatter validated (title/type/date/status) → atomic write. Unsaved-changes guard. In production a rebuild is needed for visitors to see the change.
- Implemented: bold/italic/link/headings/list/quote, Commons image search inserter (image + optional credit line). Still planned: category card, article card, photo background.
